# 模块接手指南：已实现、未实现与下一步

本文件是同学接手开发的主入口。**当前为 v0.4 联动学习工作台**，具体 API 数量/状态由 [契约索引](../contracts/README.md) 自动生成；源码和本轮真实验证见 [验收记录](../evidence/runtime-review.md)。本章不把“有表、有端口、有设计”算作功能已完成。

所有模块仍可能有完整产品范围内的剩余工作。`partial` 意味着已有可用子能力；`planned` 意味着没有当前业务实现。A/B 是待两位真实成员认领的职责标签，不能当作已完成个人贡献。

## 二、接手时必须理解的六条跨模块约束

### 1. 课程版本是一条完整边界

工作空间创建时固定 `releaseId`。知识、题目、判分、检索、导师引用与错题块都使用该发布。编辑新建 revision，不覆盖已经被发布引用的行。新发布只是改变 `active_release` 指针，新空间采用它，旧空间继续使用旧内容。历史激活不是修改学生成绩或迁移已有工作空间。

M07 原稿与清洗稿是编辑实际提交的内容；仅登记URL不会假装完成下载。M10 作者不能自审；审核固定整个内容、答案与来源哈希，发布再次计算。demo内容没有真实审核证据，不能直接混入正式发布。发布并发通过编辑锁和 `expectedActiveRevision` 收敛，旧幂等请求重放不会重新激活旧版本。

### 2. 学习活动和掌握证据分开

阅读完成、预测、浏览、生成作品、导师解释、复练按钮都不会直接加掌握分。只有 M05 服务端判分能发出 `ATTEMPT_GRADED`。同题家族首次作答形成一个独立样本，之后重试标记为练习；反馈后的正确不能覆盖首次错误。不同题目家族的新独立证据才能帮助关闭复习项。样本不足时明确显示证据不足。

Notebook 的 `submitAnswer` 从当前块的真实 `exerciseRef` 进入同一个 LearningService，不能由客户端指定答案分值、换题版本或提交到另一空间。`predict` 只记录用户预测；`requestCompile/requestHint` 等尚无对应块适配时明确503。

### 3. 上下文和作品都需要可撤回的输入

目标、记忆、作答、知识和作品引用固定 kind/id/revision/hash。当前源版本最多64条直接引用和256条传递来源，每个来源最多256个仍有效的依赖版本。保存时就限制容量，撤回才能完整完成；历史STALE版本不继续占有效额度。

目标修改、记忆撤回、作品换版在同事务中使依赖失效。自然过期也在读取/动作/下载准入时复验，不能只等待撤回事件。完整索引缺失返回 `LINEAGE_REBUILD_REQUIRED`，不绕过校验部分继续。旧 Agent epoch/lease 无法覆盖学生新稿。

### 4. 模型接入和智能质量是两件可检查的工作

EVIDENCE_ONLY 从实际检索片段整理证据，页面明确说明没有模型调用。MODEL 只有服务器URL/模型/key完整配置才受理；凭据不来自浏览器，HTTP在数据库事务外执行，禁止重定向，有响应体与时间上限。

请求先固定快照并预留额度。取消、过期、来源变化、配置变化和迟到结果都经过epoch/lease检查。已经发往供应商但没有可确认结果时，计量标UNKNOWN并保留预留，不自动重复付费调用。平台不能证明供应商真正已停止处理，也不声称取消退费。

模型只能返回规定结构和检索证据编号，不能获得隐藏标准答案、动态数据库写权限或系统命令。返回引用存在不等于所有自然语言事实正确；正式模型质量、教学效果与多专家优劣必须另做真实评测。导师转文档仍是DRAFT，并完整继承已固定的上下文与引用。

### 5. 导出成功必须意味着真实文件存在

当前导出范围为文档MD/HTML、文字/代码幻灯片HTML、关系图SVG、错题/交互作品静态HTML。队列、源版本、渲染器版本、输入hash、输出bytes/hash同属可追溯作业。成功状态与内容持久化同事务；重启不会用新renderer冒充旧renderer结果。超出范围503或受控失败，不返回空文件或虚假URL。

下载每次重新鉴权、验证完整来源和当前源版本，旧源不继续下载。HTML/SVG动态文字全部转义，无源稿脚本、网络素材或任意命令；附件响应no-store/nosniff/CSP sandbox。离线错题HTML不记录成绩，真实复练继续在在线平台执行。

### 6. 页面不能拥有第二套业务真相

前端以服务端workspace/release/revision/epoch为范围，轮询工作空间与运行的持久事件；事件用来刷新授权快照，不把payload文案当命令。切换空间取消旧请求并核对返回范围。编辑器草稿独立，409/412保留草稿并要求合并，轮询不能覆盖用户输入。202仅是任务已接受，完成后再展示文件或结果。

“P0”表示下一阶段需要优先闭合的产品链路，不表示当前未开放能力是当前已上线功能的已知安全缺陷。媒体创作是用户完整目标的必做范围，排在稳定学习与生成链之后；不能用说明文档替代最终功能。

## 四、改动交付清单

先查本模块表的写入责任与 [数据规则](03-data.md)，再改实现；接口变化同时改 OpenAPI、前端 DTO、工具协议及消费者。新能力需要行为和失败路径证据后才更新status/capabilities。

运行 `python scripts/sync_contract_index.py` 生成API索引、模块标签、累积字段字典和操作追踪，再执行静态、前后端、数据库及受影响端到端测试。历史迁移保留，旧状态文档不复制成新入口。测试结果统一在当前验收记录；计划阶段/测试存在/测试通过/最终教师验收分别描述。
