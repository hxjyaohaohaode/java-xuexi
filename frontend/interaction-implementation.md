# 交互实现与参考边界

## 设计方向

产品是 Java 泛型与类型安全学习工作台，连接规则、作答、证据和可编辑学习成果。界面性格为安静、准确、可亲近；视觉场景为阅读桌面与代码实验台。知识规则、类型表达式与真实反馈承担视觉内容，不加入虚构数据装饰。主要辨识元素为 `<T>` 标识、G01–G16 概念编号、固定版本的来源摘要与青绿色动作。

## 有意义的动态关联

1. 阅读选择关联概念 → 真实题目作答 → 学习证据与复习计划。
2. 错误或受助作答 → 错题源稿 → 预测/证据回看/复练 → 新的真实 attempt，重复题族不刷独立样本。
3. 课程知识卡 → 文档/幻灯片引用 → 固定来源的源稿版本 → 后台静态导出与真实文件下载。
4. 目标、记忆和最近作答 → 固定上下文快照 → 本地证据工作流或导师请求 → 带来源的学习文档。
5. 目标更新、归档或记忆撤回 → 上下文/任务/作品来源失效 → UI 隐藏旧导师答案并禁止旧源复练、导出。
6. 第二编辑端保存新版本 → 事件轮询重新读取 → 当前脏稿保留 → 用户比较并明确选择后续版本基线。

## 尚待专门验收的部分

本地环境禁止 Chromium 所需的内部 socket，因而本地不提供伪造截图或“已视觉验收”的结论。真实浏览器脚本已准备，移动视口、触屏目标、完整焦点流、深浅主题视觉和原生下载以 CI 的浏览器产物为准。屏幕阅读器与不同移动输入法仍需要具体设备验证；不把 DOM 渲染或代码中的媒体查询等同于已在设备上验证。
