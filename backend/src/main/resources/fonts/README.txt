TypeForgeCJK.ttf is a regular-weight subset of Noto Sans SC by the Noto Project.
Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
License: SIL Open Font License 1.1, reproduced in OFL.txt.
The variable font was instantiated at weight 400 with fontTools and subset to
Latin, punctuation, mathematical arrows, CJK and full-width glyphs. No network
font request is performed when rendering a user's file. Unavailable glyphs are
reported as an actionable export failure instead of silently disappearing.
